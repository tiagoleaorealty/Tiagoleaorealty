# Signature showcase pages

Hand-built, custom-designed property pages, each hosted at its own root URL
(`soldbytiago.com/<slug>/`). Current examples: `/villa-mariposa/`, `/villa-los-monos/`.

## How the system fits together

| Piece | Role |
|---|---|
| `/<slug>/` folder | The page itself: `index.html` + `img/`. Self-contained static files, committed to git. |
| `showcases.json` | The registry. Drives everything below. |
| `/signature/` | Public gallery, generated by `build.py` from the registry on every deploy (gitignored output). |
| Admin → Showcases tab | Read-only dashboard in `admin.html`; fetches `showcases.json`, shows URL/copy/share/open per page. |
| `sitemap.xml` | `build.py` adds `/signature/` plus every non-hidden showcase. |
| `vercel.json` | One trailing-slash redirect per page (`/<slug>` → `/<slug>/`). |

## Adding a new showcase page (checklist for Claude)

1. Build the page as a folder: `<slug>/index.html` + `<slug>/img/`.
   - Self-contained: inline CSS/JS, brand fonts embedded as data URIs
     (copy the `@font-face` blocks from an existing showcase page).
   - Brand: `#0d4a4a` teal, `#1d2021` ink, `#6b7a7a` stone, `#fafafa`/`#fdf8f2`
     grounds, Neue Haas Grotesk Display Pro, tight negative tracking on headings.
   - Head must include: canonical `https://soldbytiago.com/<slug>/`, absolute
     `og:image` URL, `og:url`, `theme-color #0d4a4a`.
   - No em dashes in copy (Tiago's preference). En dashes in numeric ranges are fine.
2. Add an entry to `showcases.json` (slug, title, location, price, tagline, hero, status, added).
3. Add the `/<slug>` → `/<slug>/` redirect to `vercel.json`.
4. Run `python3 build.py` — it fail-fasts if the folder, hero, or fields are missing.
5. Commit and have Tiago push (Claude's shell has no GitHub credentials).

## Changing or removing

- Price/title/tagline shown in the gallery and admin: edit `showcases.json`
  (and the page's own HTML if the number appears there too).
- Unpublish: set `status` to `hidden` (URL keeps working, drops out of gallery
  and sitemap) or delete the folder + entry + redirect to kill the URL.
- Mark sold: set `status` to `sold` — stays in the gallery with a SOLD badge.
- Rename a URL: rename the folder, update the slug in `showcases.json`, keep a
  permanent redirect from the old slug in `vercel.json`.

## Do not

- Do not put showcase folders under `/property/`, `/school/`, `/blog/`, or
  `/signature/` — the first three are wiped by `build.py` on every deploy, the
  last is generated output. Root-level folders only.
- Do not link external CSS/JS/fonts from a showcase page; they must render
  correctly on any device with zero external requests.
